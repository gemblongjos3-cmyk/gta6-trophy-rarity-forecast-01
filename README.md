Recency-weighted logit-linear log-time trend forecaster for GTA VI trophy earn rates on Exophase, forecasting the percent of tracked PS5 players who will have earned each trophy at the target time as five quantiles.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
